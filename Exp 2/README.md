# Experiment 2

This directory contains the Experiment 2 work, organized by sub-experiment.

## Structure

- `exp2.1/` - RESTful CRUD API using Spring Boot, including the Vercel-hosted API playground.
- `exp2.2/` - Pagination, sorting, caching, query optimization, and JMeter benchmarking.
- `exp2.3/` - JWT authentication, RBAC, AES-GCM encryption, and refresh-token lifecycle.

## Experiment 2.1
